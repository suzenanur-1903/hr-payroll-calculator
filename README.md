# HR Payroll & Bonus Calculator 📊

### 🇹🇷 Proje Hakkında
Kullanıcı girdilerine (brüt maaş, performans puanı ve güncel vergi oranı) göre çalışanların primlerini ve vergi kesintilerini hesaplayarak net maaşı döküm halinde gösteren bir Python uygulamasıdır. İK yönetim süreçlerini dijitalleştirmek amacıyla geliştirilmiştir.

### 🇬🇧 About The Project
A Python application that calculates employee performance bonuses and dynamic tax deductions based on user inputs (base salary, performance score, and current tax rate) to generate a detailed net salary payroll slip. Developed to digitize HR management workflows.

---

## 🛠️ Features / Özellikler
- **Dynamic Tax Calculation:** Vergi oranları sabit değildir, kullanıcı tarafından her hesaplamada güncellenebilir.
- **Performance-Based Bonus:** 70 ve 90 baraj puanlarına göre %10 veya %20 prim otomatik hesaplanır.
- **Clean Payroll Slip:** Brüt maaş, prim, vergi ve net ödenen tutar kuruşu kuruşuna listelenir.
